Ajustes do bot

Configure os horários e os canais de notificação. Horários só valem após reiniciar o processo.

Agendamento

Com que horários e janela de datas o bot roda.

Horários de execução automática Horários no formato HH:MM separados por vírgula. Se vazio, o bot só roda quando acionado manualmente pelo painel.
Fuso horário Ex: America/Recife. Usado para interpretar os horários acima.
Dias à frente Quantos dias além de hoje verificar. 0 = só hoje, 1 = hoje e amanhã, 7 = próxima semana.
Dias atrás Quantos dias antes de hoje incluir. 0 = só a partir de hoje, 1 = inclui ontem.
Fonte de dados

Qual calendário monitorar e quem recebe o relatório.

ID do calendário Google "primary" usa o calendário principal. Para outro, cole o ID — disponível em Configurações do Google Calendar.
E-mail para o relatório diário Recebe o resumo de cada execução.
Notificações de falha

Para onde o bot manda aviso quando algo falha. Preencha ao menos um.

Discord Webhook do canal Discord. Servidor → Integrações → Webhooks.
Google Chat Webhook de um espaço no Google Chat. Configurações do espaço → Apps e integrações.
Outro canal Slack, Teams, Zapier ou qualquer endpoint HTTP POST.
